  Электрондық қолтаңба утилитасы
  Жобаның мақсаты:
  
  Бұл жобаның мақсаты — Java бағдарламалау тілі арқылы электрондық құжатқа цифрлық қолтаңба қою және оның түпнұсқалығын тексеру жүйесін жасау.
      1. RSA-2048 алгоритмі
  Бағдарлама RSA-2048 алгоритмі арқылы екі кілт жасайды:
  - Public Key — ашық кілт. Қолтаңбаны тексеру үшін қолданылады.
  - Private Key — жабық кілт. Құжатқа қол қою үшін қолданылады.
  Жабық кілт құпия сақталуы керек.
  2. SHA256withRSA алгоритмі
  Бұл алгоритм құжатқа цифрлық қолтаңба жасау үшін қолданылады. Ол құжаттың мазмұнын тексеруге мүмкіндік береді.
  3. Бағдарламаның жұмыс істеу тәртібі
  1. RSA-2048 кілттер жұбы жасалады.
  2. Ашық және жабық кілттер PEM форматында сақталады.
  3. Пайдаланушы құжат мәтінін енгізеді.
  4. Құжат document.txt файлына сақталады.
  5. Құжатқа цифрлық қолтаңба қойылады.
  6. Қолтаңба signature.sig файлына жазылады.
  7. Бағдарлама қолтаңбаның дұрыстығын тексереді.
  4. Бағдарлама нәтижесі
   Signature valid: true
  
   Modified document valid: false
  
  - Бірінші нәтиже — қолтаңба дұрыс екенін көрсетеді.
  - Екінші нәтиже — құжат өзгертілгенде қолтаңбаның жарамсыз болатынын көрсетеді.
  
  5. Жасалған файлдар
  Файл атауы	Қызметі
  public_key.pem	Ашық кілт
  private_key.pem	Жабық кілт
  document.txt	Құжат мәтіні
  signature.sig	Цифрлық қолтаңба
  
  6. Қорытынды
  Бұл жобада Java тілінде электрондық қолтаңба жасау және тексеру жүйесі құрылды. RSA-2048 және SHA256withRSA алгоритмдері қолданылды. Бағдарлама құжаттың өзгертілмегенін тексеруге мүмкіндік береді. Жоба барысында криптография, файлдармен жұмыс және Java кітапханаларын қолдану дағдылары меңгерілді.
  Оқытушы сұрауы мүмкін сұрақтар
  1. Электрондық қолтаңба дегеніміз не?
  
  Электрондық құжаттың авторын растауға және оның өзгертілмегенін тексеруге арналған цифрлық мәлімет.
  
  2. RSA дегеніміз не?
  
  Ашық және жабық кілттерге негізделген асимметриялық криптографиялық алгоритм.
  
  3. SHA-256 не үшін қажет?
  
  Құжаттың хэш-мәнін есептеу үшін қолданылады.
  
  4. PEM форматы дегеніміз не?
  
  Кілттерді мәтіндік форматта сақтауға арналған формат.
  
  5. Құжат өзгерсе не болады?
  
  Қолтаңбаны тексеру нәтижесі false болады.
  
  6. Неліктен екі кілт қолданылады?
  
  Жабық кілтпен қол қойылады, ал ашық кілтпен қолтаңба тексеріледі.
